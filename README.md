# Para ti

Experiencia web romántica y responsiva para el 21 de septiembre.

## Recorrido

1. Portada animada con sobre, ramo y lluvia de pétalos.
2. Ramo interactivo con cinco mensajes por descubrir.
3. Sección sobre la distancia entre Colombia y Perú.
4. Mapa Bogotá-Lima con pines y contador de kilómetros.
5. Pregunta interactiva del primer encuentro.
6. Sobres para cuando la distancia se sienta pesada.
7. Carta, reencuentro y cierre con "Te amo".

## Personalización

- Los cinco mensajes están al inicio de `main.js`, en `flowerMessages`.
- Los sobres están al inicio de `main.js`, en `cartas`.
- La canción del tocadiscos usa `assets/León Larregui - Brillas (Letra).mp3`.
- Los efectos cortos están en `assets/sfx/`.
- Los textos largos están directamente en `index.html`.
- La paleta y las dimensiones responsivas están en `style.css`.
- Los PNG utilizados se encuentran en `assets/`.

No requiere compilación ni dependencias. Usa Live Server o cualquier servidor estático para probar audio local y efectos correctamente.
